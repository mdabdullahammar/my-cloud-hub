# Arabic Calligraphy Portfolio Preview

A responsive, multilingual (English / বাংলা / العربية) static portfolio concept for **mdabdullahammarofficial**.

## Live preview
Once GitHub Pages is enabled and the workflow completes, the site will be available at:
https://mdabdullahammar.github.io/my-cloud-hub/

## Notes
- This is a front-end concept preview, not the complete portfolio application.
- Artwork tiles are typographic placeholders, not photographs of finished canvases.
- The artwork tiles link to the official Facebook page.
- No database, authentication, upload system, likes, comments, or analytics are connected yet.

## Deploy
The GitHub Actions workflow in `.github/workflows/pages.yml` builds and deploys the repository root to GitHub Pages on each push to `main`.
